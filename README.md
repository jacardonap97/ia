# Ejercicios de Inteligencia Artificial

Este repositorio contiene los tres ejercicios realizados durante las sesiones de Inteligencia Artificial.

## Ejercicios

### 1. Ejercicio 1 – Algoritmo
Contiene el algoritmo que permite ordenar tres números de menor a mayor.

### 2. Ejercicio 2 – Archivo descargable
Contiene el archivo generado desde la página web utilizada durante la actividad práctica de la sesión.

### 3. Ejercicio 3 – Página web con IA
Contiene la página web desarrollada utilizando una herramienta de inteligencia artificial, aplicando lo aprendido en la sesión de Prompt Engineering.

## Uso de inteligencia artificial

En el ejercicio donde se utilizó inteligencia artificial, se incluyó el prompt utilizado para obtener el resultado, además del link de la página web.
